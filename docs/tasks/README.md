# Planes y tareas por funcionalidad

Este directorio sirve como espacio para planificar tareas por dominio y funcionalidad.

## Backlog propuesto

### Catálogo y tienda

- revisar y completar filtrar por precio/categoría
- mejorar detalle de producto y variantes
- optimizar carga de imágenes y layout

### Carrito y compra

- consolidar seguimiento de stock por variante
- mejorar flujo de checkout con validación más explícita
- revisar notificaciones y confirmación al usuario

### Pedidos y pagos

- reforzar confirmación de transferencia
- ampliar auditoría y trazabilidad
- mejorar exportación y generación de documentos

### Administración

- completar dashboard con más KPIs
- revisar permisos y accesos de staff/admin
- documentar flujos de banners y cupones

## Convenio

Cada tarea debe indicar:

- objetivo
- alcance
- dependencias
- criterio de aceptación
- persona o equipo responsable
