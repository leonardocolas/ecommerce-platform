# Especificaciones funcionales

Este directorio recopila las especificaciones clave del producto por funcionalidad.

## Especificaciones activas

- SPEC-01: Catálogo y búsqueda de productos
- SPEC-02: Carrito y checkout
- SPEC-03: Pedidos y confirmación de pago
- SPEC-04: Administración y dashboard
- SPEC-05: Gestión de banners y cupones

## Formato recomendado

Cada especificación debe incluir:

- objetivo
- actores
- flujo principal
- casos de error
- criterios de aceptación
- dependencias de backend/frontend
