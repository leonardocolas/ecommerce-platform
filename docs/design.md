# Diseño y experiencia de usuario

## Dirección visual

La interfaz del proyecto se enfoca en una compra limpia, orientada a conversiones y con una administración funcional. El frontend actual combina diseño sobrio con bloques visuales de producto, CTA claros y una navegación orientada a la tienda.

## Principios de diseño

- Claridad de información antes que ruido visual.
- Jerarquía clara entre catálogo, carrito y checkout.
- UX de comercio orientada a decisiones rápidas.
- Panel administrativo con información operativa y tablas claras.

## Páginas clave

### Storefront

- Home con valor de marca y promociones.
- Listado de productos con filtros y búsqueda.
- Detalle de producto con variantes e imágenes.
- Carrito con resumen de compra y acciones.

### Autenticación

- Login y registro con flujo de redirección.
- Recuperación de contraseña.
- Perfil de usuario con gestión de direcciones.

### Pedidos

- Historial y detalle de pedido.
- Proforma en PDF para pagos por transferencia.
- Estado visible del pedido.

### Administración

- Dashboard con KPIs.
- Gestión de productos y stock.
- Panel de usuarios, pedidos, banners y cupones.

## Sistema visual recomendado

- Fondo principal oscuro o neutro para reforzar marcas premium.
- Tarjetas con bordes suaves, ligera profundidad y espacio bien definido.
- Botones con énfasis en la acción principal.
- Se debe mantener legibilidad y consistencia en tipo, espaciado y color.

## Recomendaciones de implementación

- Mantener componentes reutilizables para producto, cards, banners y tablas.
- Diferenciar claramente estados de error, éxito y carga.
- Usar microinteracciones discretas, sin saturar la experiencia.
- Asegurar contraste y accesibilidad para textos, botones y formularios.
